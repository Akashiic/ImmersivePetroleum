**Immersive Petroleum** is a Minecraft mod, an addon for Immersive Engineering.  
It adds oil, oil extraction, and oil processing to Immersive Engineering's tech progression.

For more information and downloads, see the [CurseForge page](https://minecraft.curseforge.com/projects/immersive-petroleum) or [Modrinth page](https://modrinth.com/mod/immersivepetroleum).

If you are a modpack developer, see the [Wiki](https://github.com/TwistedGate/ImmersivePetroleum/wiki).
