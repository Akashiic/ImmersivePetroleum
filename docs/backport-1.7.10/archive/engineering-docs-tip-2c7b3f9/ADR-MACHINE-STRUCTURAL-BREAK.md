# Structural break transactions for Hydrotreater, Oil Tank and Coker Unit

Status: implementation and executable probes complete; integration run pending.

The authoritative Forge 1.7.10 runtime is `build/rfg/recompiled_minecraft-1.7.10.jar`. Bytecode inspection with `javap -c -p` confirms that `Chunk.removeTileEntity` removes its map entry before invoking `TileEntity.invalidate`. A teardown that only collects tiles still in that map omits the selected part and loses its original material. Runtime capability ownership must nevertheless require the current tile identity, a loaded chunk, the expected formed block and `!isInvalid()`.

Player removal now calls `breakByPlayer` while the selected tile still exists. Existing inventory/recovery preflight executes first. All owned parts are guarded against reentry during publication of the selected structural item. A rejected item spawn keeps that piece formed and returns false; an exception records an uncertain publication and blocks retries, including after NBT reload. Confirmed publication seals the selected part as unformed, restores the remaining structure, then lets vanilla remove the sealed internal block. Repeated invalidation cannot publish another material item.

External invalidation uses a separate structural master lookup and includes the removed tile itself in its captured part list. The removed cell is never restored over the replacement block. Other cells are restored only if they still contain the captured formed tile. A failed restoration does not silently approve the operation. An external caller that deletes a block before invoking invalidation cannot be made atomic with a third-party spawn cancellation; in that case the remaining teardown is stopped and recovery is attempted. No claim is made that arbitrary external world destruction can be reversed.

`StructuralBreakProbe`, invoked only in fresh campaign worlds, exercises eight rotations/mirror combinations for each machine. For both a real master and a real dummy, it checks cancelled item publication, attempted recursive player break, exception plus NBT reload without retry, successful removal with exactly one material item, restoration of all other parts and repeated invalidation. It also removes a real master using `World.setBlockToAir` to exercise the native map-removal ordering. Dedicated markers are required by all three PowerShell campaign runners. These probes are pending execution by the integration coordinator.
